How Menta Works

Overview

Menta uses a hashcash-style proof-of-work challenge to tell humans and bots apart. Instead of asking users to identify images, it requires their browser to solve a computational puzzle.

The puzzle is designed to be trivial for a human clicking once, but expensive for automated scripts trying to solve thousands of challenges.

The Process

1. Initialize Session

Client requests a session from /init

Server validates rate limits, checks bot signals, and creates a signed session tied to the client's IP.

2. Get Challenge

Client requests a challenge from /challenge

Server generates a random salt and target difficulty based on the client's reputation.

3. Solve Challenge

Client finds a nonce where SHA-256(salt + nonce) starts with N zeros

This requires brute-force computation, typically taking 1-3 seconds on a modern browser.

4. Redeem Token

Client submits the solution to /redeem

Server verifies the proof, validates the session, and issues a signed clearance token.

5. Verify Token

Client includes the token in form submissions

Your backend verifies the token signature and expiration via /verify.

Validation Checks

Menta runs 8 validation checks across the challenge lifecycle:

  1. Rate limit per IP. Prevents brute-force from a single address.
  2. Bot signal checks. Flags automated traffic patterns.
  3. Session validity. Verifies session exists, hasn't expired, and matches IP.
  4. Session signature. HMAC proves session originated from this server.
  5. Challenge signature. HMAC proves challenge originated from this server.
  6. Nonce entropy. Ensures nonce isn't precomputed or reused.
  7. Proof-of-work. Hash must meet target difficulty.
  8. Client pattern. Solve time analyzed against human range.

Adaptive Difficulty

Menta automatically adjusts difficulty based on client behavior:

  • New IPs get higher difficulty until they establish reputation
  • Fast solves trigger difficulty increase (possible bot)
  • Many failures significantly increase difficulty
  • Consistent patterns may indicate automation
