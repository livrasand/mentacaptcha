Features

Privacy by Design

  • Zero third-party telemetry. No requests to Google, Cloudflare, or any external service.
  • No cookies or fingerprints. Visitor data stays on your server.
  • IP truncation. IPs truncated to /24 (IPv4) or /64 (IPv6) by default.
  • Anonymous support. Open tickets without personal data.

Bot Protection

  • Proof-of-work challenges. Computational puzzles that are trivial for humans, expensive for bots.
  • Adaptive difficulty. Automatically adjusts based on client behavior.
  • Rate limiting. Per-IP and global rate limits prevent abuse.
  • Bot signal detection. Flags suspicious traffic patterns before challenges.
  • Session validation. HMAC-signed sessions tied to client IP.

Developer Experience

  • Simple integration. Two lines of HTML to get started.
  • Customizable widget. Full control via data attributes.
  • Internationalization. All text configurable.
  • Theme support. Light, dark, or auto mode.
  • Custom CSS. Inject your own styles.

Self-hosted & Free

  • Open source. Full source code available on GitHub.
  • No limits. Unlimited domains, unlimited challenges.
  • No vendor lock-in. Run anywhere Python is supported.
  • Optional encryption. SQLCipher support for data at rest.

Compliance

  • Data minimization. Collect only what's necessary.
  • Configurable retention. Automatic cleanup of old data.
  • Subject rights. Export and delete endpoints for DSAR.
  • Audit logging. Track admin access and changes.
