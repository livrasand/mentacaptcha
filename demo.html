What's happening?

  1. Your browser computes a SHA-256 hash until it finds one that starts with zeros
  2. The solution is sent to the server for verification
  3. Server issues a signed token valid for the session duration

Privacy Note

Menta does not use cookies, fingerprints, or third-party telemetry. Your users click once; the proof-of-work runs silently.
